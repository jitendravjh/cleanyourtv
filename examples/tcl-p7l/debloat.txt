# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv (HDMI 1 is

# Keep: com.tcl.tv, com.tcl.tvinput, com.tcl.suspension, com.tcl.dashboard, com.tcl.autopair,
# com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup, com.tcl.factory.view, com.tcl.useragreement,
# com.tcl.globalkeyoverlay, com.tcl.inputmethod.international, com.tcl.hearaid, all com.realtek.* and com.tvos.
# Kept by choice: Chromecast, AirPlay, Assistant and the remote's mic, USB media, YouTube, Netflix, Prime Video.
#
# Firmware updates are off by choice. TCL's updater is inside com.tcl.ttvs (versionUpdateApp
# SystemUpdateService), so it goes with TCL's analytics. Settings > System update opens Google Play
# Services' updater (com.google.android.gms/.update.SystemUpdatePanoActivity), which cannot be disabled
# without breaking the Play Store. Automatic installs are off for it instead:
#   tools/tv.py 'settings put global ota_disable_automatic_update 1'   (undo: settings delete global ota_disable_automatic_update)
#
# Changed outside the list, so restore.sh leaves them; the undo is on the right:
#   screensaver_components  in.jitendravjh.cleanyourtv/.ClockDream   settings put secure screensaver_components com.google.android.apps.tv.dreamx/.service.Backdrop
#   ota_disable_automatic_update  1                         settings delete global ota_disable_automatic_update
#   time_12_24  12 (was 24, so the clock shows AM/PM)       settings put system time_12_24 24
#   location_mode  3 (was 0, the Wi-Fi pill reads the name)  cmd location set-location-enabled false
# Launcher setup: launcher/build-and-install.sh with INPUT_KEY_SERVICE=1 HOME_KEY_SERVICE=1 (it also grants
# APP_AUTO_START, this firmware's name for the op), then
#   tools/theme.sh examples/tcl-p7l/theme   (dock, the HDMI 1 tile, remote keys, stock_home_redirect)
#
# Known quirks on this firmware:
# - The home network is IPv6-only, so the TV has no usable IPv4: TV_HOST is its fe80:: address with %en0.
# - Set up in full Google TV mode. In basic mode the firmware leaves out the four apps under
#   "Shown only in full Google TV mode" below.
# - The Wi-Fi joined in the setup wizard belongs to setupwraith: forget and re-join it in Settings
#   before disable.sh can turn setupwraith off.
# - Settings > Reset, and Accounts and Profiles, hand off to setupwraith, so they do nothing while it is
#   disabled. Turning setupwraith back on alone gives the TV no Home (its RecoveryActivity takes HOME and
#   loops while launcherx is off). Run restore.sh with launcherx first, then reset.
